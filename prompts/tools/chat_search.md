name: "Tool: chat_search"
description: "Find past conversations that mention something."
-->
Search the text of past Chat and Telegram conversations, archived ones included, and get
back matching messages with their thread title and date. Use it for "what did we say
about X", "find that conversation where..." -- things said, not facts learned. For what
you know about the user use memory_recall; memory holds facts, this holds the
conversations. Matching is literal, so search a distinctive word rather than a sentence.
