Draw a picture from a description and put it in the conversation. Use it when the user
asks for an image, a drawing, an illustration or a mock-up of something that does not
exist yet. Describe the subject, the setting and the style in the prompt; the model sees
nothing else, so "a poster for it" without saying what "it" is produces a poster of
nothing. It costs a provider call and takes several seconds, so do not draw something
nobody asked for, and never use it to reproduce a real person, a logo or a copyrighted
character. It cannot edit an existing image.
