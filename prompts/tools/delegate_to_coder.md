Hand a coding job to a coding agent and get back a job id. Use it for anything that
means reading or changing source code -- you are not the thing that edits code. Default
mode is investigate, which is read-only; fix lets it edit and needs the user's say-so.
It takes minutes and returns immediately: keep talking, then use delegated_status.
