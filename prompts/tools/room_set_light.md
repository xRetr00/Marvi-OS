Turn the room light on or off, or set brightness and colour temperature. Read room_state
first -- acting on an assumed state is how you switch off a light that was already off
and report the opposite. Say what happened only after seeing it in the state that comes
back; an accepted call is not a light that changed. When the room is asleep the light
can only go off, enforced outside your reach, so a refusal there is not something to
work around.
