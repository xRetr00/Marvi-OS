Record a standing fact about the user so it is remembered in every future conversation.
This is the memory that describes the person rather than the world: their name, their
role, how they like to be answered. Not for passing details, not for anything about the
current task, and not for a fact about a thing -- memory_remember is for those. Never
write a password, code, card or ID number here.
