Stop a delegated sub-agent job by id when the owner says to -- "forget it", "stop that".
Work it already did stays done: files it changed stay changed, and a desktop or browser
action already in flight finishes, but nothing further is sent. It does not pause the
computer; the Island's Stop does that. Say that you stopped it. Use delegated_status
first if you are not sure which job they mean.
