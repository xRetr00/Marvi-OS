Put text on the clipboard so the user can paste it with Ctrl+V -- a command, an address,
a reply you drafted. Use it when they ask you to copy something, or when what they need
is easier pasted than dictated. It replaces whatever they had copied, which is gone
afterwards, so do not use it unasked. Say that it is on the clipboard.
