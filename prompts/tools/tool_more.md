Read the rest of a result that came back cut off. A long result is shortened before it
reaches you, with a handle printed where it was cut; pass that handle here to read on,
and pass the `to` of one slice as the `offset` of the next. Use it when the part you were
given does not contain the answer -- not by reflex, because the first slice usually does.
A handle stops working after a while and after a restart; run the original tool again if
it does.
