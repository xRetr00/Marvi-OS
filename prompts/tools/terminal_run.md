Run a shell command in the terminal: PowerShell, cmd, or sh. Use for git, npm, python,
builds, and anything a command line does. For reading, searching and editing files the
file tools, glob and grep are better than their shell equivalents. A build or test suite
that takes minutes goes in the background: set `background`, keep working, and read what
it printed with process_output.
