Open a visible saved browser profile. Usually this is Talos's job: if the user wants
something *done* on a website, hand the whole task to Talos with delegate rather than
opening a browser and working it yourself. For a question the web can answer, search
instead. One browser per profile -- if it refuses, it names the open session and its
revision; use that one.
