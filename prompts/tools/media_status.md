How loud the speakers are right now, 0 to 100, and whether they are muted. Read it before
any change the user asked for in relative terms -- "a bit quieter", "half as loud", "back
to normal" -- because media_control cannot work out where it started. It says nothing
about what is playing, only the level Windows has the speakers at.
