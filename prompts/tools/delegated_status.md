Check delegated work by id: a sub-agent job or a job handed to an outside coder. It says
whether it is still running, waiting for the owner's approval, or finished, and gives the
report if there is one. The report is written to be spoken -- give the user its answer,
not a list of file paths. Omit the id to see every job.
